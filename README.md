## Profil Perusahaan: Rootera Plumbing (Jaya & Jawa Group)

**Rootera Plumbing** merupakan unit bisnis dan anak perusahaan resmi di bawah naungan holding company **Jaya & Jawa (J&J) Group**. Perusahaan ini bergerak secara khusus sebagai penyedia **jasa spesialis saluran pipa mampet profesional** dengan standar mekanikal modern.

### Prinsip Operasional Utama Rootera:
1. **100% Tanpa Bongkar (*Non-Destructive Method*):**  
   Penanganan sumbatan dilakukan langsung melalui lubang pembuangan (*floor drain* atau *cleanout*). Tidak merusak keramik lantai, tidak membongkar dinding beton, dan tidak merusak estetika bangunan.
2. **100% Tanpa Soda Api (*Zero Caustic Chemicals*):**  
   Menolak penggunaan soda api (*Natrium Hidroksida / NaOH*) dan bahan kimia korosif yang berisiko melelehkan sambungan pipa PVC, menyebabkan pipa melengkung, serta menimbulkan kebocoran tersembunyi.
3. **Peralatan Mekanikal & Optik Modern:**
   - **Mesin Spiral Rotary Elektrik:** Kabel baja karbon fleksibel berputar dengan torsi tinggi menembus lekukan siku pipa 90° (*elbow* dan *P-trap*).
   - **Kamera Inspeksi CCTV Pipa 1080p Waterproof:** Diagnosis endoskopi visual kondisi pipa secara *live* disertai rekaman autentik *Sebelum & Sesudah* bagi klien.
   - **High-Pressure Hydro-Jetting:** Semburan air kinetik bertekanan ekstrem hingga 3.500+ PSI untuk membersihkan kerak lemak membatu dan endapan lumpur pekat.

## Fitur Responsivitas Lintas Perangkat

Aplikasi dibangun dengan metodologi **Mobile-First Responsive Web Design** untuk menjamin tampilan sempurna pada setiap resolusi:

1. **Layar Ponsel Kecil (320px - 480px, misal iPhone SE & Android Compact):**
   - Menambahkan pembatas `min-w-[320px] overflow-x-hidden w-full` pada `body` dan kontainer utama untuk mencegah bug *horizontal scroll*.
   - Seluruh tombol aksi secara cerdas beralih menjadi ukuran penuh (*full-width*) dengan tinggi target sentuh jari minimal 44px.
   - Ukuran font input formulir diatur ke `text-base sm:text-sm` (minimal 16px di layar sentuh) guna mencegah Safari iOS melakukan *auto-zoom* yang mengacaukan layout saat pengguna mengetik.
   - Tautan navigasi footer diatur dalam *grid 2 kolom* simetris (`grid grid-cols-2`) sehingga teks panjang tidak terhimpit menjadi kolom vertikal sempit.
2. **Layar Tablet (640px - 1023px, iPad / Tablet Android):**
   - Grid layout bertransformasi secara proporsional menjadi 2 kolom.
   - Tombol CTA otomatis bertransisi menjadi susunan horizontal yang seimbang.
3. **Layar Desktop & Monitor Lebar (1024px - 1920px+):**
   - Navigasi atas simetris tiga zona (Brand kiri, Menu navigasi tengah, Tombol aksi kanan).
   - Grid kartu 3 kolom penuh dengan efek *hover elevation* halus.

## Optimasi SEO (Search Engine Optimization)

Website ini dioptimasi penuh agar ramah mesin pencari Google dan media sosial:

### 1. Schema.org JSON-LD Structured Data
Kedua halaman mengimplementasikan metadata terstruktur standar W3C:
- `@type: Person` (Yero Virdhan Akifan, Lead Tim IT & Siswa SMK RPL).
- `@type: PlumbingService` (Rootera Plumbing, spesialis saluran pipa mampet, nomor telepon, afiliasi Jaya & Jawa Group).
- `@type: WebPage` & `WebSite` (Canonical URL dan nama situs).
- `@type: BreadcrumbList` (Navigasi hierarkis Google Search Console).

### 2. Social Meta Tags (Open Graph & Twitter Cards)
- `og:locale`: `id_ID`
- `og:title` & `og:description` tertarget kata kunci: *Jasa Saluran Pipa Mampet, Anti Mampet Tanpa Bongkar, Mesin Spiral Rotary, Siswa SMK RPL, Rootera Plumbing, Jaya & Jawa Group*.
- `og:image`: Dimensi standar resolusi tinggi 3000 x 4000 piksel dengan metadata aman.

### 3. File Crawling Mesin Pencari
- **`public/robots.txt`:** Mengizinkan pengindeksan seluruh halaman dan mengarahkan bot perayap ke sitemap.
- **`public/sitemap.xml`:** Memetakan URL `/`, `/rootera-experience`, gambar utama, frekuensi pembaruan mingguan, dan prioritas perayapan (1.0 & 0.9).

## Panduan Instalasi & Menjalankan Proyek

### Prasyarat Sistem
- PHP versi **8.2** atau **8.3+**
- Composer versi **2.x+**
- Web Server lokal: **Laragon**, XAMPP, Valet, atau PHP Built-in Server.

### Langkah-Langkah Menjalankan
1. **Buka Terminal di Direktori Proyek:**
   ```bash
   cd c:\laragon\www\portofolio
   ```

2. **Pasang Dependensi Composer (bila diperlukan):**
   ```bash
   composer install
   ```

3. **Pengaturan Berkas Lingkungan (`.env`):**
   Pastikan berkas `.env` telah ada. Jika belum, salin dari `.env.example`:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. **Bersihkan & Optimalkan Cache:**
   ```bash
   php artisan optimize:clear
   ```

5. **Jalankan Aplikasi:**
   - Melalui **Laragon:** Buka peramban dan akses [http://portofolio.test](http://portofolio.test)
   - Melalui **Artisan Server:**
     ```bash
     php artisan serve
     ```
     Lalu buka [http://127.0.0.1:8000](http://127.0.0.1:8000) pada peramban web Anda.

## Pengujian Otomatis (Automated Testing)

Proyek ini dilengkapi rangkaian pengujian otomatis menggunakan **PHPUnit** pada berkas `tests/Feature/ExampleTest.php` untuk memverifikasi fungsionalitas dan integritas konten:

```bash
php artisan test
```

### Lingkup Verifikasi Test Suite:
1. `test_the_application_returns_a_successful_response`:
   - Memastikan rute `/` mengembalikan kode status **200 OK**.
   - Memastikan identitas *"Yero Virdhan Akifan"*, domain *"rooteraplumbing.id"*, nomor WA *"0815-1996-7047"*, holding *"Jaya & Jawa"*, kejuruan *"Rekayasa Perangkat Lunak"*, dan lencana *"DOMINAN"* termuat secara tepat.
2. `test_the_rootera_experience_page_returns_a_successful_response`:
   - Memastikan rute `/rootera-experience` mengembalikan kode status **200 OK**.
   - Memastikan entitas *"Rootera Plumbing"*, *"DOMINAN (70% FOKUS)"*, dan *"SMK RPL"* tervalidasi.
3. `test_robots_txt_returns_successful_response`:
   - Memastikan `/robots.txt` berstatus 200 dengan header `text/plain` dan instruksi `User-agent`.
4. `test_sitemap_xml_returns_successful_response`:
   - Memastikan `/sitemap.xml` berstatus 200 dengan header `application/xml` dan elemen `<urlset>`.
